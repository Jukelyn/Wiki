## Obtaining

The Composter is a single-block [Basic Machine](https://github.com/Slimefun/Slimefun4/wiki/Basic-Machines).

## Usage

It can be used to create dirt, netherrack, soul sand and netherwart from organic materials. This can be very useful early on to get some nether items.

## Recipes

<center>

| Input      | Output      |
| ---------- | ----------- |
| 4 Wheat    | Nether Wart |
| 2 Sand     | Soul Sand   |
| 4 Stone    | Netherrack  |
| 4 Andesite | Netherrack  |
| 4 Diorite  | Netherrack  |
| 4 Granite  | Netherrack  |
| 8 Leaves   | Dirt        |
| 8 Saplings | Dirt        |
| 8 Azalea   | Dirt        |

</center>
